The OKF Specification

The open, vendor-neutral baseline definition. Capturing concepts as plain markdown files with parseable YAML frontmatter makes cataloged knowledge highly readable and portable.

Initial Bundle Creation

Bootstrapping an OKF bundle (/okf) on a brownfield or greenfield codebase involves scanning directories (mapping existing systems or planning new architectures) to identify core abstractions and schemas, then outputting the folder structure.

  • Executes directory listings and search queries to map project subsystems.
  • Identifies models, database schemas, scripts, and API routes.
  • Establishes folders (like tables/, playbooks/) and initial root index files.
  • Sets up the foundation for continuous code-knowledge synchronization.

Capture knowledge as an **OKF bundle**: a directory of markdown **concept** files, each carrying YAML **frontmatter** plus a free-form body. No SDK, no central authority — readable, diffable, portable. Spec: https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md

> **Model-Tier Steering:** Use the **High** reasoning setting of the active model when bootstrapping a new OKF bundle or synthesizing architectural concepts. Once the concept boundaries and implementation plan are laid out, switch back to the **Medium** setting of the same model for implementation and routine upkeep.

## Authoring a concept

1. **Locate the bundle root.** Find the existing bundle directory, or create one for a new bundle. Concepts live in it, nested in subdirectories as the subject warrants.
   - Done when you have an absolute bundle root and know where this concept's file goes.

2. **Write the concept file.** One `.md` file per concept: a frontmatter block delimited by `---`, then the markdown body. See **Frontmatter** and **Body** below.
   - Done when the file has parseable YAML frontmatter with a non-empty `type`, and a body that stands on its own to a reader with no tools.

3. **Cross-link.** Link related concepts inline in the body with bundle-relative absolute paths: `[Orders table](/schemas/orders.md)`. Links assert plain, untyped relationships. A link to a concept you haven't written yet is fine — broken links are tolerated.
   - Done when every related concept you reference is linked.

4. **Update reserved files.** If the bundle has an `index.md`, add the new concept to it. Append a dated line to `log.md` if one exists. If bootstrapping a new bundle, ensure the root `index.md` contains the frontmatter `okf_version: 0.2`. See **Reserved files**.
   - Done when `index.md` lists the concept and `log.md` records the change — for each reserved file the bundle actually uses.

5. **Steering Notice (AGENTS.md / CLAUDE.md / .cursorrules / .windsurfrules / .clinerules / GEMINI.md).** If bootstrapping a new bundle or if repository root-level agent steering files do not mention the OKF bundle, create or update the appropriate agent configuration file depending on the active CLI/agent environment:
   - **Detection**:
     * If the executing agent environment is **Claude Code** (e.g., command is `claude`, or environment variables/tools like `AskUserQuestion` indicate Claude Code), target **`CLAUDE.md`**.
     * If the executing agent environment is **Google Antigravity / Gemini CLI** (e.g., command is `agy`, or tools like `ask_permission`/`ask_question` indicate Antigravity), target **`AGENTS.md`** (or **`GEMINI.md`** if preferred).
     * If the environment is **Cursor IDE**, target **`.cursorrules`** or **`AGENTS.md`**.
     * If the environment is **Windsurf**, target **`.windsurfrules`** or **`AGENTS.md`**.
     * If the environment is **Cline / Roo Code**, target **`.clinerules`** or **`AGENTS.md`**.
     * Otherwise (e.g. Codex, OpenHands, general agents), default to creating **`AGENTS.md`**.
   - **Content**: 
     * Include a **Pre-Work Grounding Gate** instructing agents before inspecting code, planning architecture, answering system questions, or modifying files to: (1) query the bundle (`node okf-query/scripts/query.js --search <keywords>` or inspect `index.md`), (2) retrieve file/module contracts (`node okf-query/scripts/query.js --file <path>`), (3) explicitly cite consulted concepts, and (4) follow **Model-Tier Routing** (use the **High** reasoning setting of the active model during initial bundle bootstrapping, domain/architecture discovery, and implementation planning, then switch back to the **Medium** setting of that same model once the plan is laid out and approved before executing implementation tasks).
     * Include a **Pre-Completion Verification Gate** instructing agents before completing any work (keeping the active model on its **Medium** setting for post-implementation upkeep) to: (1) perform **Semantic Concept & Source Binding Upkeep** (updating affected concept prose or creating a new concept, binding all newly created or modified source files in the concept's `resource:` or `sources:` frontmatter so they graduate out of `## Not yet specified` in `index.md`, and recording a summary in `log.md`), (2) run `okf-maintain` (or `node okf-maintain/scripts/maintain.js`), and (3) run `okf-lint --drift` (or `node okf-lint/scripts/lint.js --drift`).
     * Create or update the selected steering file with a dedicated **Knowledge Bundle / OKF** section.
     * Direct future agent sessions to first verify workspace synchronization on startup (running `okf-lint --drift` to detect drift, and `okf-maintain` to fix/sync any drift).
     * Instruct them to locate and use the **closest parent `okf/` directory** relative to the file they are editing (falling back to the root `okf/` if no local directory exists).
     * Instruct them to ground any initial user questions about the codebase by searching the OKF bundle first (e.g., running `okf-query --search <keywords>` or checking `index.md`) before answering or planning.
     * Instruct them to run `okf-query --file <file-path>` before analyzing/editing files to pull context.
     * Instruct them to maintain the bundle post-edit by running `okf-maintain` followed by `okf-lint` to update or create concepts if they modify schemas/components/APIs, discover platform/sandbox-specific constraints (e.g., mobile WebView quirks, CORS limits, CDN blockages), improve developer utility/test pages, or learn new codebase behaviors/patterns that warrant a permanent guideline.
     * Include the steering version tracking tag at the bottom of the section: `<!-- okf-steering-version: 1.8.2 -->`.
   - Done when the target root-level agent steering file (`AGENTS.md`, `CLAUDE.md`, `.cursorrules`, etc.) exists and contains the tailored OKF steering directives with the version tag.


6. **Conformance gate.** Verify the bundle still conforms. See **Conformance**.
   - Done when every non-reserved `.md` has parseable frontmatter with a non-empty `type`, and each reserved file matches its structure.


## Frontmatter

**Required** — the only hard rule:

- `type` — the kind of concept, non-empty (e.g. `BigQuery Table`, `Playbook`, `Service`, `Metric`, `Attested Computation`). Free-form; pick a consistent vocabulary within a bundle.

**Recommended & Lifecycle / Trust Fields (OKF v0.2)** — add when they apply:

- `title` — display name
- `description` — one-sentence summary
- `resource` — URI of the underlying asset the concept describes
- `tags` — list for cross-cutting categorization
- `status` — lifecycle status: `draft` | `stable` | `deprecated` (defaults to `stable`)
- `stale_after` — ISO 8601 UTC timestamp instant on/after which the concept is considered stale (e.g. `2026-12-31T00:00:00Z`)
- `generated` — structured map recording who produced the concept (`by`, in actor format: `<producer>/<version>` for agents, `human:<id>` for people, or `process:<id>` for automated processes) and when (`at`, ISO 8601 UTC timestamp; run `date -u +%Y-%m-%dT%H:%M:%SZ` — don't guess)
- `verified` — list (or single mapping) of verification events (`- { by: <actor>, at: <ISO-8601> }`). Derives trust tier: `unverified` (no verifier), `machine-confirmed` (automated verifiers), or `human-reviewed` (`human:` verifier).
- `sources` — structured list of references/provenance artifacts the concept derives from:
  - `resource` (REQUIRED): absolute URL, bundle-relative path (`/...`), or scope descriptor.
  - `id`: stable key used for per-claim attribution via footnotes `[^id]`.
  - `title`, `author`, `usage_count`, `last_modified` (ISO 8601).
- `usage_window` — optional sibling of `sources` framing `usage_count`: `{ from: <ISO-8601>, to: <ISO-8601> }`.

**Attested Computations (type: Attested Computation)**:
Carries a sanctioned way to compute a value:
- `runtime` (REQUIRED): execution environment (e.g. `bigquery`, `postgres`, `python`, `dbt`).
- `parameters`: list of typed inputs (`- { name: <str>, type: <str>, required: <bool> }`).
- `computation`: path to an external query/code file (if not provided inline under `# Computation`).
- `executor`: `{ resource: <path-to-skill-or-runner>, receipt: [<fields>] }`.
- `attester`: `{ resource: <path-to-deterministic-verifier-code> }`.

```markdown
---
type: BigQuery Table
title: Orders
description: One row per customer order, partitioned by order date.
resource: bigquery://project.dataset.orders
tags: [sales, core]
status: stable
stale_after: 2026-12-31T00:00:00Z
generated:
  by: human:developer
  at: 2026-08-05T14:08:30Z
verified:
  - by: process:nightly-validator
    at: 2026-08-06T02:00:00Z
sources:
  - id: ga4-schema
    resource: https://developers.google.com/analytics/bigquery/export-schema
    title: GA4 BigQuery Export schema
    author: team:ga4-docs
    last_modified: 2026-08-01T00:00:00Z
---

Orders is the system of record for placed orders.[^ga4-schema]

[^ga4-schema]: GA4 BigQuery Export schema
```

## Body

Free-form markdown. Use these conventional headings when they fit, so consumers find the material where they expect it:

- `# Schema` — structured field/column descriptions
- `# Examples` — usage demonstrations
- `# Computation` — the sanctioned computation block of an `Attested Computation` (when not using external `computation: <file>`)

## Directory Organization & Scaling

To prevent catalog clutter as the number of concepts increases, adhere to the following organization guidelines:
- **Flat Layout (< 10 concepts):** Keep all concepts at the root (`/okf/*.md`) for simpler cross-linking.
- **Nested Layout (>= 10 concepts):** Organize concepts into standard logical subdirectories:
  - `/subsystems/` — Core software modules, services, and API route logic.
  - `/data/` — Database schemas, entity models, and cache configurations.
  - `/operations/` — Deployment scripts, CI/CD, and quality assurance/testing setups.
  - `/playbooks/` — Common procedures, runbooks, and recovery checklists.

## Reserved files

Two reserved filenames, both optional — but if present, keep them current (step 4):

- `index.md` — a listing of the directory's concepts, enabling progressive disclosure of a large bundle. For OKF v0.2, the root `index.md` may include `okf_version: "0.2"` in its frontmatter (no other `index.md` may contain frontmatter).
- `log.md` — an update history, newest changes recorded chronologically. Date headings MUST use ISO 8601 `YYYY-MM-DD` form (e.g. `## 2026-08-24`).

## Conformance

Hard rules — a bundle conforms only if all hold:

1. Every non-reserved `.md` file has parseable YAML frontmatter.
2. Every frontmatter has a non-empty `type`.
3. Reserved files (`index.md`, `log.md`) follow their structures above.

Everything else is soft guidance. When reading a bundle, degrade gracefully: tolerate unknown `type` values, missing recommended fields, and broken links (which may represent not-yet-written knowledge per §6.1) rather than erroring.

# `okf-wayfinder` Workflow

Guide the developer through creating a brand new, fully conforming OKF v0.2 concept file using a mix of automated codebase telemetry and brief interactive questions.

> **Model-Tier Steering:** Use the **High** reasoning setting of the active model during initial bundle bootstrapping and interactive concept discovery interviews. Once the architecture and implementation plan are laid out, switch back to the **Medium** setting of the same model for implementation and routine upkeep.

## Steps

1. **Locate the Bundle & Scan Registry**
   - Check `/docs/okf` or `/okf` for the bundle root. If none exists, ask if you should initialize a new one. If initializing, create the root `index.md` containing `okf_version: 0.2` in its frontmatter, create `log.md`, and create or update the appropriate root-level agent steering file (`AGENTS.md`, `CLAUDE.md`, `.cursorrules`, `.windsurfrules`, `.clinerules`, or `GEMINI.md`) as detailed in Step 5 of the core `okf` skill to guide future agents.
   - Scan existing concepts to extract defined `types`, `tags`, existing `concepts` (with their `markdownLink` paths), bundle `layoutMode` (`flat` vs `nested`) and `subdirectories`, and untracked workspace files (`frontier` and clustered `frontierGroups`). This prevents vocabulary fragmentation and surfaces undocumented modules.
   - Run the utility script:
     ```bash
     node <path-to-skill-directory>/scripts/wayfinder_taxonomy.js [--bundle <path>]
     ```

2. **Categorize the Concept & Propose Clustered Frontier Candidates**
   - Read the `frontierGroups` (clustered module candidates with a `primaryCandidate`, `companionFiles`, and `suggestedType`) and `frontier` returned by the taxonomy script.
   - Propose undocumented module groups or files directly to the user (e.g., *"I see these undocumented modules/files in the workspace. Would you like to create a concept for one of them, or document a different concept?"*).
   - Use the host environment's structured question tool when available (`ask_question` in Antigravity, `AskUserQuestion` in Claude Code) or fall back to a concise plain-text menu to select the concept `type` (highlighting existing bundle types alongside standard OKF types: `Concept`, `Skill`, `Utility`, `Playbook`, `Decision`, `Attested Computation`).
   - Ensure that all links between concepts use descriptive name labels from `concepts[].markdownLink` (e.g., `[Label](/concepts/target.md)`) rather than bare filenames or URLs.

3. **Autogenerate a Telemetry Draft (If Applicable)**
   - If the concept maps to one or more workspace files (e.g., a controller, SQL migration, skill, or deploy script), inspect the primary file with the telemetry flag and read relevant source files:
     ```bash
     node <path-to-skill-directory>/scripts/wayfinder_taxonomy.js --inspect <file-path> [--bundle <path>]
     ```
   - Use the telemetry output (`exportedSymbols`, `localImports`, `relatedConcepts`, and `git.lastModified` / `git.primaryAuthors`) to pre-populate:
     - Primary asset binding in `resource:` (`file:///...`) and companion module files in `sources:` so that all files in the module graduate out of `## Not yet specified` in `index.md`.
     - Candidate inline cross-links using `relatedConcepts[].markdownLink`.
     - Suggested failover/review owners from `git.primaryAuthors`.

4. **Conduct the Focus Interview (Type-Aware)**
   - Ask **at most 3 targeted questions** (using structured question tools where appropriate) to extract tribal knowledge that static code analysis cannot infer, tailored to the chosen `type`:
     - **Service / Subsystem / Concept:** *"What are the SLA expectations, critical failure modes, or non-obvious architectural constraints?"*
     - **Database / Data Model:** *"What is the data retention/partitioning policy, and who owns upstream ingestion?"*
     - **Playbook / Operations:** *"What triggers this runbook, who is the escalation contact if it fails, and when should it be re-verified (`stale_after`, e.g., 90 or 180 days)?"*
     - **Decision (ADR):** *"What problem context forced this decision, what alternatives were rejected, and what are the trade-offs?"*
     - **Attested Computation:** *"What is the execution `runtime` (e.g., `bigquery`, `postgres`, `python`, `dbt`), what typed `parameters` are required, and which scripts act as `executor` and `attester`?"*

5. **Draft, Attest Human Verification, and Sync Lifecycle**
   - Compile the inputs into a clean `.md` concept file placed according to `layoutMode` and existing `subdirectories` (see **Directory Organization & Scaling**).
   - Populate OKF v0.2 frontmatter:
     - Required `type`, plus `title`, `description`, `resource`, `tags`, `status: stable`, and `sources` (binding all companion files).
     - `generated: { by: <producer>/<version>, at: <UTC-ISO-timestamp> }`.
     - **Human-Reviewed Trust Attestation (`verified`):** Present the draft to the developer for confirmation. Because `okf-wayfinder` is an interactive human-in-the-loop interview, once the developer approves the concept, record their sign-off in `verified:` (using `git.suggestedVerifierActor` or `human:<id>`):
       ```yaml
       verified:
         - by: human:<developer-id>
           at: <UTC-ISO-timestamp>
       ```
       This immediately graduates the concept from `unverified` to the **`human-reviewed`** trust tier.
     - If `type: Attested Computation`, include `runtime` (required), `parameters`, `computation` (or an inline `# Computation` section), `executor`, and `attester`.
     - If time-sensitive (e.g., `Playbook`, `Decision`, SLA contract), set `stale_after` to an ISO 8601 UTC expiration timestamp.
   - Add the concept to `index.md` and record a summary in `log.md` under a `## YYYY-MM-DD` date heading.
   - **Automated Post-Authoring Verification:** Run `okf-maintain` and `okf-lint --drift` to graduate bound files out of `## Not yet specified` in `index.md` and verify 0 errors and 0 warnings:
     ```bash
     node okf-maintain/scripts/maintain.js
     node okf-lint/scripts/lint.js --drift
     ```

wayfinder_taxonomy.js (Taxonomy & Telemetry Scanner) 
const fs = require('fs');
const path = require('path');
const { execFileSync } = require('child_process');

function scanBundleTaxonomy(dir, bundleRoot, workspaceRoot, taxonomy) {
  if (!fs.existsSync(dir)) return taxonomy;
  for (const file of fs.readdirSync(dir)) {
    const fullPath = path.join(dir, file);
    const stat = fs.statSync(fullPath);
    if (stat.isDirectory()) {
      if (file.toLowerCase() === 'archive') continue;
      scanBundleTaxonomy(fullPath, bundleRoot, workspaceRoot, taxonomy);
    } else if (stat.isFile() && file.endsWith('.md')) {
      if (/^(index|log)\.md$/i.test(file)) continue;
      const fm = parseFrontmatter(fs.readFileSync(fullPath, 'utf8'));
      if (!fm) continue;
      if (fm.type) taxonomy.types.add(fm.type);
      if (Array.isArray(fm.tags)) fm.tags.forEach(t => taxonomy.tags.add(t));
      // Tracks resource, sources, computation, executor.resource, and attester.resource
      const relToBundle = '/' + path.relative(bundleRoot, fullPath).replace(/\\/g, '/');
      const title = fm.title || path.basename(file, '.md');
      taxonomy.concepts.push({ title, type: fm.type, bundlePath: relToBundle, markdownLink: `[${title}](${relToBundle})` });
    }
  }
  return taxonomy;
}

Context-Aware Query Engine

The /okf-query skill retrieves matching OKF concepts matching specific file paths or text queries, enabling agents to instantly load relevant architectural boundaries, dependencies, and business constraints directly into memory.

  • Resolves codebase file paths relative to workspace roots to find corresponding resource mappings.
  • Performs keyword search queries across concept titles, tags, types, and bodies.
  • Consolidates matches into a single markdown block optimized for prompt injection.

# `okf-query` Workflow

Retrieve matching OKF v0.2 concepts to inject architectural contracts, provenance, and trust signals directly into agent prompts.

## Usage

```bash
# Retrieve concept matching a specific codebase resource, source, or attested computation file
node okf-query/scripts/query.js --file install.ps1 [--bundle <path>]

# Search all concepts by tags, provenance metadata, runtime, or text keywords
node okf-query/scripts/query.js --search "maintenance" [--bundle <path>]
```

## Steps

1. **Locate the Bundle**
   - Locate the OKF bundle root directory at `/docs/okf` or `/okf` (or via `--bundle <path>`), skipping `archive/` directories so only active concepts are injected.

2. **Match by File Path (`--file <path>`)**
   - Take a file path as input and resolve it relative to the workspace root.
   - Scan all active concept files and inspect all OKF v0.2 §6.2 path-valued fields: `resource`, `sources` (both shorthand string arrays and `{ id, resource, title, ... }` objects), `computation`, `executor.resource`, and `attester.resource`.
   - **Tier 1 (Direct / Enclosing Match):** Select any concept whose bound path matches the queried file or an enclosing parent directory, ranking primary resource bindings (`resource`, `computation`, `executor.resource`, `attester.resource`) ahead of secondary `sources` mentions. If the queried path does not exist on disk at that exact relative path, fall back to suffix and basename matching against bound resources before attempting directory matching.
   - **Tier 2 (Subsystem / Directory Match):** If no Tier 1 match exists, select concepts that document sibling files in the same module/directory.
   - If no concept is found, output actionable guidance suggesting search keywords or the catalog index.

3. **Match by Text Search (`--search <query>`)**
   - Scan concept `title`, `description`, `type`, `runtime`, `tags`, `resource`, `sources` (`id`, `resource`, `title`, `author`), `computation`, `executor.resource`, `attester.resource`, and markdown body text.

4. **Consolidated Output**
   - Output selected concepts formatted as an `=== OKF CONTEXT BLOCK ===` including `Type`, `Description`, `Resource`, `Runtime`/`Computation` (for `Attested Computation`), `Tags`, `Status`, `Stale After`, derived `Trust Tier` (`unverified`, `machine-confirmed`, or `human-reviewed` per §5.3), and body content.

const fs = require('fs');
const path = require('path');
const { execFileSync } = require('child_process');
const os = require('os');

function resolveTelemetryPath(args = []) {
  if (process.env.OKF_DISABLE_TELEMETRY === '1' || process.env.OKF_INTERNAL_CALL === '1') return null;
  const idx = args.indexOf('--telemetry');
  if (idx !== -1 && args[idx + 1]) return path.resolve(args[idx + 1]);
  if (process.env.OKF_TELEMETRY_PATH) return path.resolve(process.env.OKF_TELEMETRY_PATH);
  try {
    const cwdNorm = path.resolve(process.cwd()).toLowerCase();
    const tmpNorm = path.resolve(os.tmpdir()).toLowerCase();
    if (cwdNorm.startsWith(tmpNorm)) return null;
  } catch (e) {}
  return path.join(os.homedir(), '.okf', 'telemetry.jsonl');
}

function recordTelemetry(entry, args = []) {
  const telPath = resolveTelemetryPath(args);
  if (!telPath) return;
  try {
    const dir = path.dirname(telPath);
    if (!fs.existsSync(dir)) fs.mkdirSync(dir, { recursive: true });
    const payload = {
      timestamp: new Date().toISOString(),
      ...entry
    };
    fs.appendFileSync(telPath, JSON.stringify(payload) + '\n', 'utf8');
  } catch (e) {}
}

function splitRespectingQuotes(str, delimiter = ',') {
  const result = [];
  let current = '';
  let inDouble = false;
  let inSingle = false;
  for (let i = 0; i < str.length; i++) {
    const char = str[i];
    if (char === '"' && !inSingle) {
      inDouble = !inDouble;
      current += char;
    } else if (char === "'" && !inDouble) {
      inSingle = !inSingle;
      current += char;
    } else if (char === delimiter && !inDouble && !inSingle) {
      result.push(current);
      current = '';
    } else {
      current += char;
    }
  }
  result.push(current);
  return result;
}

function parseFrontmatter(content) {
  const match = content.match(/^---\r?\n([\s\S]*?)\r?\n---/);
  if (!match) return null;
  const fmText = match[1];
  
  function parseInlineValue(val) {
    val = val.trim();
    if (val.startsWith('{') && val.endsWith('}')) {
      const obj = {};
      const pairs = splitRespectingQuotes(val.slice(1, -1), ',');
      for (const pair of pairs) {
        const colonIdx = pair.indexOf(':');
        if (colonIdx === -1) continue;
        const k = pair.slice(0, colonIdx).trim();
        let v = pair.slice(colonIdx + 1).trim();
        if ((v.startsWith('"') && v.endsWith('"')) || (v.startsWith("'") && v.endsWith("'"))) {
          v = v.slice(1, -1);
        }
        obj[k] = v;
      }
      return obj;
    }
    if (val.startsWith('[') && val.endsWith(']')) {
      return splitRespectingQuotes(val.slice(1, -1), ',').map(item => {
        item = item.trim();
        if ((item.startsWith('"') && item.endsWith('"')) || (item.startsWith("'") && item.endsWith("'"))) {
          item = item.slice(1, -1);
        }
        return item;
      });
    }
    if ((val.startsWith('"') && val.endsWith('"')) || (val.startsWith("'") && val.endsWith("'"))) {
      return val.slice(1, -1);
    }
    return val;
  }

  const fm = {};
  const lines = fmText.split(/\r?\n/);
  let currentKey = null;
  let inArray = false;

  for (let i = 0; i < lines.length; i++) {
    const line = lines[i];
    if (!line.trim() || line.trim().startsWith('#')) continue;

    const matchIndent = line.match(/^(\s*)/);
    const indent = matchIndent ? matchIndent[1].length : 0;
    const trimmed = line.trim();

    if (trimmed.startsWith('-')) {
      const rest = trimmed.slice(1).trim();
      if (!currentKey) continue;
      if (!Array.isArray(fm[currentKey])) {
        fm[currentKey] = [];
      }
      
      if (rest.startsWith('{') && rest.endsWith('}')) {
        fm[currentKey].push(parseInlineValue(rest));
      } else {
        const colonIdx = rest.indexOf(':');
        if (colonIdx !== -1 && !/^[a-zA-Z][a-zA-Z0-9+.-]*:\/\//.test(rest)) {
          const k = rest.slice(0, colonIdx).trim();
          const v = parseInlineValue(rest.slice(colonIdx + 1).trim());
          const obj = {};
          obj[k] = v;
          fm[currentKey].push(obj);
        } else {
          fm[currentKey].push(parseInlineValue(rest));
        }
      }
      inArray = true;
      continue;
    }

    const colonIdx = trimmed.indexOf(':');
    if (colonIdx === -1) continue;

    const key = trimmed.slice(0, colonIdx).trim();
    const val = parseInlineValue(trimmed.slice(colonIdx + 1).trim());

    if (indent === 0) {
      currentKey = key;
      inArray = false;
      if (val === '') {
        fm[key] = {};
      } else {
        fm[key] = val;
      }
    } else {
      if (inArray && currentKey && Array.isArray(fm[currentKey])) {
        const lastItem = fm[currentKey][fm[currentKey].length - 1];
        if (lastItem && typeof lastItem === 'object') {
          lastItem[key] = val;
        }
      } else if (currentKey && fm[currentKey] && typeof fm[currentKey] === 'object') {
        fm[currentKey][key] = val;
      }
    }
  }
  return fm;
}

function getConceptBody(content) {
  return content.replace(/^---[\s\S]*?---\r?\n/, '');
}

function resolveResourceLocalPath(resourceUri, workspaceRoot, bundleRoot = null) {
  if (!resourceUri || typeof resourceUri !== 'string') return null;
  const trimmed = resourceUri.trim();
  if (/^(?!file:\/\/)[a-zA-Z][a-zA-Z0-9+.-]*:\/\//i.test(trimmed)) return null;
  if (/^(?!file:)[a-zA-Z][a-zA-Z0-9+.-]+:/i.test(trimmed)) return null;
  if (!/^file:\/\//i.test(trimmed) && /\s/.test(trimmed) && !/[\/\\]/.test(trimmed)) return null;

  const isFileUri = /^file:\/\//i.test(trimmed);
  let localPath = trimmed.replace(/^file:\/\/\/?/, '').replace(/[?#].*$/, '');
  try {
    localPath = decodeURIComponent(localPath);
  } catch (e) {}
  if (!isFileUri && trimmed.startsWith('/') && bundleRoot) {
    const bundleCandidate = path.normalize(path.join(bundleRoot, localPath.slice(1)));
    if (fs.existsSync(bundleCandidate)) return bundleCandidate;
    const workspaceCandidate = path.normalize(path.join(workspaceRoot, localPath.slice(1)));
    if (fs.existsSync(workspaceCandidate)) return workspaceCandidate;
  }
  if (path.isAbsolute(localPath)) {
    const absNorm = path.normalize(localPath);
    if (fs.existsSync(absNorm)) return absNorm;
    const stripped = localPath.replace(/^[\/\\]+/, '');
    const relCandidate = path.normalize(path.join(workspaceRoot, stripped));
    if (fs.existsSync(relCandidate)) return relCandidate;
    return absNorm;
  }
  if (bundleRoot) {
    const bundleRelCandidate = path.normalize(path.join(bundleRoot, localPath));
    if (fs.existsSync(bundleRelCandidate) && !fs.existsSync(path.join(workspaceRoot, localPath))) {
      return bundleRelCandidate;
    }
  }
  return path.normalize(path.join(workspaceRoot, localPath));
}

function collectPrimaryResourceUris(fm) {
  const uris = [];
  if (!fm) return uris;
  if (fm.resource) uris.push(fm.resource);
  if (fm.computation) uris.push(fm.computation);
  if (fm.executor && fm.executor.resource) uris.push(fm.executor.resource);
  if (fm.attester && fm.attester.resource) uris.push(fm.attester.resource);
  return uris;
}

function collectSecondarySourceUris(fm) {
  const uris = [];
  if (!fm || !Array.isArray(fm.sources)) return uris;
  for (const src of fm.sources) {
    const rawResource = typeof src === 'string' ? src : (src && src.resource);
    if (rawResource) uris.push(rawResource);
  }
  return uris;
}

function collectConceptResourceUris(fm) {
  return [...collectPrimaryResourceUris(fm), ...collectSecondarySourceUris(fm)];
}

function scanConcepts(dir, bundleRoot, workspaceRoot, matches = []) {
  if (!fs.existsSync(dir)) return matches;
  const files = fs.readdirSync(dir);
  for (const file of files) {
    const fullPath = path.join(dir, file);
    const stat = fs.statSync(fullPath);
    if (stat.isDirectory()) {
      if (file.toLowerCase() === 'archive') continue;
      scanConcepts(fullPath, bundleRoot, workspaceRoot, matches);
    } else if (stat.isFile() && file.endsWith('.md')) {
      if (file === 'index.md' || file === 'log.md') continue;
      try {
        const content = fs.readFileSync(fullPath, 'utf8');
        const fm = parseFrontmatter(content);
        const body = getConceptBody(content);
        if (fm) {
          matches.push({
            relativePath: path.relative(bundleRoot, fullPath).replace(/\\/g, '/'),
            absolutePath: fullPath,
            frontmatter: fm,
            body: body
          });
        }
      } catch (e) {}
    }
  }
  return matches;
}

function resolveWorkspaceAndBundle(args) {
  const cwd = process.cwd();
  const bundleIdx = args.indexOf('--bundle');
  if (bundleIdx !== -1 && args[bundleIdx + 1]) {
    const bundleRoot = path.resolve(cwd, args[bundleIdx + 1]);
    if (fs.existsSync(bundleRoot)) {
      const parentDir = path.dirname(bundleRoot);
      const derivedRoot = path.basename(parentDir).toLowerCase() === 'docs'
        ? path.dirname(parentDir)
        : parentDir;
      return { workspaceRoot: derivedRoot, bundleRoot };
    }
    return { workspaceRoot: cwd, bundleRoot };
  }

  let bundleRoot = path.join(cwd, 'docs', 'okf');
  if (!fs.existsSync(bundleRoot)) {
    bundleRoot = path.join(cwd, 'okf');
  }
  return { workspaceRoot: cwd, bundleRoot };
}

function tokenizeSearchQuery(rawQuery) {
  if (!rawQuery || typeof rawQuery !== 'string') return [];
  const rawTokens = rawQuery
    .toLowerCase()
    .split(/\s+/)
    .map(t => t.replace(/^[^a-z0-9_./-]+|[^a-z0-9_./-]+$/g, ''))
    .filter(Boolean);
  const stopwords = new Set(['a', 'an', 'the', 'to', 'in', 'on', 'of', 'or', 'and', 'for', 'by', 'is', 'at', 'with', 'from']);
  const meaningful = rawTokens.filter(t => t.length > 2 || !stopwords.has(t));
  return meaningful.length > 0 ? meaningful : rawTokens;
}

function main() {
  const startTime = Date.now();
  const args = process.argv.slice(2);
  const fileIndex = args.indexOf('--file');
  const searchIndex = args.indexOf('--search');

  if (fileIndex === -1 && searchIndex === -1) {
    console.error('Usage: node okf-query/scripts/query.js --file <path> OR --search <keyword>');
    process.exit(1);
  }

  const { workspaceRoot, bundleRoot } = resolveWorkspaceAndBundle(args);

  if (!fs.existsSync(bundleRoot)) {
    console.error(`Error: OKF bundle not found.`);
    process.exit(1);
  }

  const allConcepts = scanConcepts(bundleRoot, bundleRoot, workspaceRoot);
  const matchedEntries = [];
  const searchKeyword = searchIndex !== -1 && args[searchIndex + 1] ? args[searchIndex + 1].toLowerCase().trim() : null;
  const searchTokens = searchKeyword ? tokenizeSearchQuery(searchKeyword) : [];

  if (fileIndex !== -1) {
    const rawFileArg = args[fileIndex + 1];
    const wsTarget = path.resolve(workspaceRoot, rawFileArg);
    const cwdTarget = path.resolve(process.cwd(), rawFileArg);
    const targetFile = fs.existsSync(wsTarget) || !fs.existsSync(cwdTarget) ? wsTarget : cwdTarget;
    const targetExists = fs.existsSync(targetFile);
    const normalizedTarget = path.normalize(targetFile).toLowerCase();

    // Tier 1A (primary resource) & Tier 1B (secondary sources): Exact file match or enclosing directory resource
    const tier1Primary = [];
    const tier1Secondary = [];
    for (const c of allConcepts) {
      let matchedPrimary = false;
      for (const uri of collectPrimaryResourceUris(c.frontmatter)) {
        const resPath = resolveResourceLocalPath(uri, workspaceRoot, bundleRoot);
        if (resPath) {
          const normalizedRes = path.normalize(resPath).toLowerCase();
          if (normalizedTarget === normalizedRes || normalizedTarget.startsWith(normalizedRes + path.sep)) {
            tier1Primary.push({ concept: c, matchTier: 'primary' });
            matchedPrimary = true;
            break;
          }
        }
      }
      if (matchedPrimary) continue;

      for (const uri of collectSecondarySourceUris(c.frontmatter)) {
        const resPath = resolveResourceLocalPath(uri, workspaceRoot, bundleRoot);
        if (resPath) {
          const normalizedRes = path.normalize(resPath).toLowerCase();
          if (normalizedTarget === normalizedRes || normalizedTarget.startsWith(normalizedRes + path.sep)) {
            tier1Secondary.push({ concept: c, matchTier: 'secondary' });
            break;
          }
        }
      }
    }
    matchedEntries.push(...tier1Primary, ...tier1Secondary);

    // Tier 1C: Suffix / Basename fallback when the queried path does not exist at that exact relative location
    if (matchedEntries.length === 0 && !targetExists) {
      const rawRelNorm = rawFileArg.replace(/\\/g, '/').replace(/^\.?\//, '').toLowerCase();
      const targetBase = path.basename(normalizedTarget);
      const suffixPrimary = [];
      const suffixSecondary = [];
      const basePrimary = [];
      const baseSecondary = [];

      for (const c of allConcepts) {
        let hitPrimarySuffix = false;
        let hitPrimaryBase = false;
        for (const uri of collectPrimaryResourceUris(c.frontmatter)) {
          const resPath = resolveResourceLocalPath(uri, workspaceRoot, bundleRoot);
          if (!resPath) continue;
          const resRel = path.relative(workspaceRoot, resPath).replace(/\\/g, '/').toLowerCase();
          const resBase = path.basename(resPath).toLowerCase();
          if (rawRelNorm.includes('/') && (resRel === rawRelNorm || resRel.endsWith('/' + rawRelNorm))) {
            suffixPrimary.push({ concept: c, matchTier: 'primary', fallback: 'fallback-suffix' });
            hitPrimarySuffix = true;
            break;
          }
          if (targetBase && resBase === targetBase) {
            basePrimary.push({ concept: c, matchTier: 'primary', fallback: 'fallback-basename' });
            hitPrimaryBase = true;
          }
        }
        if (hitPrimarySuffix) continue;

        for (const uri of collectSecondarySourceUris(c.frontmatter)) {
          const resPath = resolveResourceLocalPath(uri, workspaceRoot, bundleRoot);
          if (!resPath) continue;
          const resRel = path.relative(workspaceRoot, resPath).replace(/\\/g, '/').toLowerCase();
          const resBase = path.basename(resPath).toLowerCase();
          if (rawRelNorm.includes('/') && (resRel === rawRelNorm || resRel.endsWith('/' + rawRelNorm))) {
            suffixSecondary.push({ concept: c, matchTier: 'secondary', fallback: 'fallback-suffix' });
            break;
          }
          if (!hitPrimaryBase && targetBase && resBase === targetBase) {
            baseSecondary.push({ concept: c, matchTier: 'secondary', fallback: 'fallback-basename' });
            break;
          }
        }
      }

      if (suffixPrimary.length > 0 || suffixSecondary.length > 0) {
        matchedEntries.push(...suffixPrimary, ...suffixSecondary);
      } else if (basePrimary.length > 0 || baseSecondary.length > 0) {
        matchedEntries.push(...basePrimary, ...baseSecondary);
      }
    }

    // Tier 2: Directory / Subsystem match (target resides in the same directory as a documented resource)
    if (matchedEntries.length === 0) {
      const wsNorm = path.normalize(workspaceRoot).toLowerCase();
      const tier2Primary = [];
      const tier2Secondary = [];
      for (const c of allConcepts) {
        let matchedDirPrimary = false;
        for (const uri of collectPrimaryResourceUris(c.frontmatter)) {
          const resPath = resolveResourceLocalPath(uri, workspaceRoot, bundleRoot);
          if (resPath) {
            const resDir = path.dirname(path.normalize(resPath)).toLowerCase();
            if (resDir !== wsNorm && (normalizedTarget === resDir || normalizedTarget.startsWith(resDir + path.sep))) {
              tier2Primary.push({ concept: c, matchTier: 'directory' });
              matchedDirPrimary = true;
              break;
            }
          }
        }
        if (matchedDirPrimary) continue;

        for (const uri of collectSecondarySourceUris(c.frontmatter)) {
          const resPath = resolveResourceLocalPath(uri, workspaceRoot, bundleRoot);
          if (resPath) {
            const resDir = path.dirname(path.normalize(resPath)).toLowerCase();
            if (resDir !== wsNorm && (normalizedTarget === resDir || normalizedTarget.startsWith(resDir + path.sep))) {
              tier2Secondary.push({ concept: c, matchTier: 'directory' });
              break;
            }
          }
        }
      }
      matchedEntries.push(...tier2Primary, ...tier2Secondary);
    }
  } else if (searchIndex !== -1 && searchKeyword) {
    const exactAndFullMatches = [];
    const partialMatches = [];

    for (const c of allConcepts) {
      const title = (c.frontmatter.title || '').toLowerCase();
      const desc = (c.frontmatter.description || '').toLowerCase();
      const type = (c.frontmatter.type || '').toLowerCase();
      const runtime = (c.frontmatter.runtime || '').toLowerCase();
      const tags = (c.frontmatter.tags || []).map(t => String(t).toLowerCase());
      const relPath = (c.relativePath || '').toLowerCase();
      const body = c.body.toLowerCase();
      let sourcesText = '';
      for (const uri of collectConceptResourceUris(c.frontmatter)) {
        sourcesText += ' ' + String(uri).toLowerCase();
      }
      if (Array.isArray(c.frontmatter.sources)) {
        for (const src of c.frontmatter.sources) {
          if (src && typeof src === 'object') {
            if (src.title) sourcesText += ' ' + String(src.title).toLowerCase();
            if (src.description) sourcesText += ' ' + String(src.description).toLowerCase();
            if (src.author) sourcesText += ' ' + String(src.author).toLowerCase();
            if (src.id) sourcesText += ' ' + String(src.id).toLowerCase();
          }
        }
      }

      const headerBlob = [title, desc, type, runtime, tags.join(' '), relPath, sourcesText].join(' ');
      const fullBlob = headerBlob + '\n' + body;

      const isHeaderExactPhrase =
        title.includes(searchKeyword) ||
        desc.includes(searchKeyword) ||
        type.includes(searchKeyword) ||
        runtime.includes(searchKeyword) ||
        tags.some(t => t.includes(searchKeyword)) ||
        sourcesText.includes(searchKeyword);
      const isExactPhrase = isHeaderExactPhrase || body.includes(searchKeyword);

      let tokenHitCount = 0;
      let headerTokenHits = 0;
      let weightedScore = (isExactPhrase ? 100 : 0) + (isHeaderExactPhrase ? 50 : 0);
      for (const tok of searchTokens) {
        if (fullBlob.includes(tok)) {
          tokenHitCount++;
          let inHeader = false;
          if (title.includes(tok)) {
            weightedScore += 10;
            inHeader = true;
          }
          if (tags.some(t => t.includes(tok)) || relPath.includes(tok)) {
            weightedScore += 8;
            inHeader = true;
          }
          if (desc.includes(tok)) {
            weightedScore += 6;
            inHeader = true;
          }
          if (sourcesText.includes(tok)) {
            weightedScore += 4;
            inHeader = true;
          }
          if (inHeader) {
            headerTokenHits++;
          } else {
            weightedScore += 1;
          }
        }
      }
      weightedScore += headerTokenHits * 5;

      if (isExactPhrase || (searchTokens.length > 1 && tokenHitCount === searchTokens.length)) {
        exactAndFullMatches.push({ concept: c, tokenHitCount, weightedScore });
      } else if (searchTokens.length >= 2 && tokenHitCount >= Math.max(2, Math.ceil(searchTokens.length * 0.5))) {
        partialMatches.push({ concept: c, tokenHitCount, weightedScore });
      }
    }

    const chosen = exactAndFullMatches.length > 0 ? exactAndFullMatches : partialMatches;
    chosen.sort((a, b) => (b.tokenHitCount - a.tokenHitCount) || (b.weightedScore - a.weightedScore));
    for (const item of chosen) {
      matchedEntries.push({ concept: item.concept, matchTier: 'search' });
    }
  }

  if (matchedEntries.length === 0) {
    if (fileIndex !== -1) {
      const relTarget = path.relative(workspaceRoot, path.resolve(workspaceRoot, args[fileIndex + 1]));
      console.log(`No matching OKF concepts found for file: ${relTarget}`);
      console.log(`Tip: Try searching by keyword: node okf-query/scripts/query.js --search <module-or-topic>`);
      console.log(`Or inspect the catalog index at: ${fs.existsSync(path.join(bundleRoot, 'index.md')) ? path.relative(workspaceRoot, path.join(bundleRoot, 'index.md')).replace(/\\/g, '/') : 'docs/okf/index.md'}`);
    } else {
      console.log('No matching OKF concepts found.');
    }
    const durationMs = Date.now() - startTime;
    const anomalies = ['query_miss'];
    if (durationMs > 2000) anomalies.push('slow_exec');
    recordTelemetry({
      skill: 'okf-query',
      workspaceRoot,
      mode: fileIndex !== -1 ? 'file' : 'search',
      query: fileIndex !== -1 ? args[fileIndex + 1] : args[searchIndex + 1],
      matchCount: 0,
      matchTiers: [],
      outputBytes: 0,
      durationMs,
      anomalies
    }, args);
    return;
  }

  const forceFull = args.includes('--full');
  const MAX_CONCEPT_CHARS = 12000;
  const MAX_FILE_FULL_CONCEPTS = 3;
  const MAX_SEARCH_FULL_CONCEPTS = 5;

  function formatConceptBody(concept) {
    const trimmed = concept.body.trim();
    if (forceFull || trimmed.length <= MAX_CONCEPT_CHARS) {
      return trimmed;
    }

    const lines = trimmed.split(/\r?\n/);
    const sections = [];
    let current = { heading: '(Introduction)', lines: [] };
    for (const line of lines) {
      if (/^#{1,3}\s+/.test(line)) {
        if (current.lines.length > 0 || current.heading !== '(Introduction)') {
          sections.push(current);
        }
        current = { heading: line.trim(), lines: [line] };
      } else {
        current.lines.push(line);
      }
    }
    if (current.lines.length > 0) sections.push(current);

    const toc = sections
      .filter(s => s.heading !== '(Introduction)')
      .map(s => '  ' + s.heading)
      .join('\n');

    if (searchKeyword) {
      let matchingSections = sections.filter(s =>
        s.heading.toLowerCase().includes(searchKeyword) ||
        s.lines.join('\n').toLowerCase().includes(searchKeyword)
      );
      if (matchingSections.length === 0 && searchTokens.length > 1) {
        matchingSections = sections.filter(s => {
          const secText = (s.heading + '\n' + s.lines.join('\n')).toLowerCase();
          return searchTokens.some(tok => secText.includes(tok));
        });
      }
      if (matchingSections.length > 0) {
        const excerpt = matchingSections.map(s => s.lines.join('\n').trim()).join('\n\n---\n\n');
        if (excerpt.length <= MAX_CONCEPT_CHARS) {
          return `[Concept Outline (${concept.relativePath})]\n${toc}\n\n[Matching Sections for "${args[searchIndex + 1]}"]\n${excerpt}\n\n(Note: Showing matching sections from ${concept.relativePath} [${trimmed.length} chars total]. Pass --full to print entire concept.)`;
        }
      }
    }

    return `${trimmed.slice(0, MAX_CONCEPT_CHARS)}\n\n... [Truncated at ${MAX_CONCEPT_CHARS} of ${trimmed.length} chars from ${concept.relativePath}. Pass --full or read ${concept.relativePath} directly for remaining sections]\nSection Outline:\n${toc}`;
  }

  // Format and output matched concepts
  let outputBytes = 0;
  const origConsoleLog = console.log;
  console.log = (...logArgs) => {
    outputBytes += Buffer.byteLength(logArgs.map(String).join(' ') + '\n', 'utf8');
    origConsoleLog(...logArgs);
  };
  console.log(`=== OKF CONTEXT BLOCK (${matchedEntries.length} concept(s) found) ===\n`);
  for (let idx = 0; idx < matchedEntries.length; idx++) {
    const entry = matchedEntries[idx];
    const c = entry.concept;
    console.log(`[Concept: ${c.frontmatter.title || c.relativePath}]`);
    console.log(`File:        ${c.relativePath}`);
    console.log(`Type:        ${c.frontmatter.type}`);
    if (c.frontmatter.description) console.log(`Description: ${c.frontmatter.description}`);
    if (c.frontmatter.resource)    console.log(`Resource:    ${c.frontmatter.resource}`);
    if (c.frontmatter.runtime)     console.log(`Runtime:     ${c.frontmatter.runtime}`);
    if (c.frontmatter.computation) console.log(`Computation: ${c.frontmatter.computation}`);
    if (c.frontmatter.tags)        console.log(`Tags:        ${c.frontmatter.tags.join(', ')}`);
    if (c.frontmatter.status)      console.log(`Status:      ${c.frontmatter.status}`);
    if (c.frontmatter.stale_after) console.log(`Stale After: ${c.frontmatter.stale_after}`);
    
    let trustTier = 'unverified';
    if (c.frontmatter.verified) {
      const verifications = Array.isArray(c.frontmatter.verified) ? c.frontmatter.verified : [c.frontmatter.verified];
      const hasHuman = verifications.some(v => v && v.by && String(v.by).startsWith('human:'));
      trustTier = hasHuman ? 'human-reviewed' : 'machine-confirmed';
    }
    console.log(`Trust Tier:  ${trustTier}`);
    
    console.log(`----------------------------------------`);
    const shouldPrintFull =
      forceFull ||
      (entry.matchTier === 'search'
        ? idx < MAX_SEARCH_FULL_CONCEPTS
        : (entry.matchTier === 'primary' || idx < MAX_FILE_FULL_CONCEPTS));

    if (shouldPrintFull) {
      console.log(formatConceptBody(c));
    } else if (entry.matchTier === 'search') {
      console.log(`(Additional search match [${idx + 1} of ${matchedEntries.length}]. Read ${c.relativePath} or pass --full for full concept body.)`);
    } else {
      console.log(`(Matched via secondary sources: binding [${idx + 1} of ${matchedEntries.length}]. Read ${c.relativePath} or pass --full for full concept body.)`);
    }
    console.log(`\n========================================\n`);
  }
  console.log = origConsoleLog;

function splitRespectingQuotes(str, delimiter = ',') {
  const result = [];
  let current = '';
  let inDouble = false;
  let inSingle = false;
  for (let i = 0; i < str.length; i++) {
    const char = str[i];
    if (char === '"' && !inSingle) {
      inDouble = !inDouble;
      current += char;
    } else if (char === "'" && !inDouble) {
      inSingle = !inSingle;
      current += char;
    } else if (char === delimiter && !inDouble && !inSingle) {
      result.push(current);
      current = '';
    } else {
      current += char;
    }
  }
  result.push(current);
  return result;
}

function parseFrontmatter(content) {
  const match = content.match(/^---\r?\n([\s\S]*?)\r?\n---/);
  if (!match) {
    return { frontmatter: {}, body: content };
  }
  const fmText = match[1];
  const body = content.slice(match[0].length).trim();
  
  function parseInlineValue(val) {
    val = val.trim();
    if (val.startsWith('{') && val.endsWith('}')) {
      const obj = {};
      const pairs = splitRespectingQuotes(val.slice(1, -1), ',');
      for (const pair of pairs) {
        const colonIdx = pair.indexOf(':');
        if (colonIdx === -1) continue;
        const k = pair.slice(0, colonIdx).trim();
        let v = pair.slice(colonIdx + 1).trim();
        if ((v.startsWith('"') && v.endsWith('"')) || (v.startsWith("'") && v.endsWith("'"))) {
          v = v.slice(1, -1);
        }
        obj[k] = v;
      }
      return obj;
    }
    if (val.startsWith('[') && val.endsWith(']')) {
      return splitRespectingQuotes(val.slice(1, -1), ',').map(item => {
        item = item.trim();
        if ((item.startsWith('"') && item.endsWith('"')) || (item.startsWith("'") && item.endsWith("'"))) {
          item = item.slice(1, -1);
        }
        return item;
      });
    }
    if ((val.startsWith('"') && val.endsWith('"')) || (val.startsWith("'") && val.endsWith("'"))) {
      return val.slice(1, -1);
    }
    return val;
  }

  const fm = {};
  const lines = fmText.split(/\r?\n/);
  let currentKey = null;
  let inArray = false;

  for (let i = 0; i < lines.length; i++) {
    const line = lines[i];
    if (!line.trim() || line.trim().startsWith('#')) continue;

    const matchIndent = line.match(/^(\s*)/);
    const indent = matchIndent ? matchIndent[1].length : 0;
    const trimmed = line.trim();

    if (trimmed.startsWith('-')) {
      const rest = trimmed.slice(1).trim();
      if (!currentKey) continue;
      if (!Array.isArray(fm[currentKey])) {
        fm[currentKey] = [];
      }
      
      if (rest.startsWith('{') && rest.endsWith('}')) {
        fm[currentKey].push(parseInlineValue(rest));
      } else {
        const colonIdx = rest.indexOf(':');
        if (colonIdx !== -1 && !/^[a-zA-Z][a-zA-Z0-9+.-]*:\/\//.test(rest)) {
          const k = rest.slice(0, colonIdx).trim();
          const v = parseInlineValue(rest.slice(colonIdx + 1).trim());
          const obj = {};
          obj[k] = v;
          fm[currentKey].push(obj);
        } else {
          fm[currentKey].push(parseInlineValue(rest));
        }
      }
      inArray = true;
      continue;
    }

    const colonIdx = trimmed.indexOf(':');
    if (colonIdx === -1) continue;

    const key = trimmed.slice(0, colonIdx).trim();
    const val = parseInlineValue(trimmed.slice(colonIdx + 1).trim());

    if (indent === 0) {
      currentKey = key;
      inArray = false;
      if (val === '') {
        fm[key] = {};
      } else {
        fm[key] = val;
      }
    } else {
      if (inArray && currentKey && Array.isArray(fm[currentKey])) {
        const lastItem = fm[currentKey][fm[currentKey].length - 1];
        if (lastItem && typeof lastItem === 'object') {
          lastItem[key] = val;
        }
      } else if (currentKey && fm[currentKey] && typeof fm[currentKey] === 'object') {
        fm[currentKey][key] = val;
      }
    }
  }
  return { frontmatter: fm, body };
}

function extractLinks(body, docDir, bundleRoot) {
  // Strip fenced code blocks and inline backticked code
  const stripped = body
    .replace(/```[\s\S]*?```/g, '')
    .replace(/`[^`\r\n]+`/g, '');

  const linkRe = /\]\(([^)\s]+\.md)(?:#[A-Za-z0-9_\-]*)?\)/g;
  const out = [];
  const seen = new Set();
  const bundleRootResolved = path.resolve(bundleRoot);

  let match;
  while ((match = linkRe.exec(stripped)) !== null) {
    const target = match[1];
    if (target.includes('://')) {
      continue;
    }
    try {
      let resolvedPath;
      if (target.startsWith('/')) {
        resolvedPath = path.join(bundleRootResolved, target);
      } else {
        resolvedPath = path.resolve(docDir, target);
      }
      const relative = path.relative(bundleRootResolved, resolvedPath);
      let rel = relative.split(path.sep).join('/');
      if (rel.endsWith('.md')) {
        rel = rel.slice(0, -3);
      }
      if (rel && !seen.has(rel)) {
        seen.add(rel);
        out.push(rel);
      }
    } catch (e) {
      // Ignore resolving errors
    }
  }
  return out;
}

function walkConcepts(dir, bundleRoot, list = []) {
  const files = fs.readdirSync(dir);
  for (const file of files) {
    const fullPath = path.join(dir, file);
    const stat = fs.statSync(fullPath);
    if (stat.isDirectory()) {
      if (file.toLowerCase() === 'archive') continue;
      walkConcepts(fullPath, bundleRoot, list);
    } else if (stat.isFile() && file.endsWith('.md')) {
      const lowerFile = file.toLowerCase();
      if (lowerFile === 'index.md' || lowerFile === 'log.md') {
        continue;
      }
      list.push(fullPath);
    }
  }
  return list;
}

function buildGraph(concepts) {

        parameters: c.parameters,
        computation: c.computation,
        executor: c.executor,
        attester: c.attester
      }
    };
  });

  const edges = [];
  const seenEdges = new Set();

  for (const c of concepts) {
    for (const target of c.links_to) {
      if (target === c.id || !ids.has(target)) {
        continue;
      }
      const key = `${c.id}__${target}`;
      if (seenEdges.has(key)) {

      edges.push({
        data: {
          id: `${c.id}__${target}`,
          source: c.id,
          target: target
        }
      });
    }
  }

  const bodies = {};
  for (const c of concepts) {
    bodies[c.id] = c.body;
  }

  const types = Array.from(new Set(concepts.map(c => c.type))).sort();

  return {
    nodes,
    edges,
    bodies,
    types,
    palette: TYPE_PALETTE
  };
}

      conceptId = conceptId.slice(0, -3);
    }

    const { frontmatter, body } = parseFrontmatter(content);
    if (!frontmatter.type) {
      // Conformance check: OKF documents must contain a type field
      continue;
    }

    let tags = frontmatter.tags || [];
    if (!Array.isArray(tags)) {
      tags = [String(tags)];
    }

    let sources = frontmatter.sources || [];
    if (!Array.isArray(sources)) {
      sources = [sources];
    }

    const links = extractLinks(body || '', path.dirname(mdPath), bundleRoot);
    const candidatePathFields = [];
    for (const src of sources) {
      const rawResource = typeof src === 'string' ? src : (src && src.resource);
      if (rawResource) candidatePathFields.push(rawResource);
    }
    if (frontmatter.computation) candidatePathFields.push(frontmatter.computation);
    if (frontmatter.executor && frontmatter.executor.resource) candidatePathFields.push(frontmatter.executor.resource);
    if (frontmatter.attester && frontmatter.attester.resource) candidatePathFields.push(frontmatter.attester.resource);

    for (const rawResource of candidatePathFields) {
      if (typeof rawResource === 'string' && !/^[a-zA-Z][a-zA-Z0-9+.-]*:\/\//i.test(rawResource)) {
        if (rawResource.startsWith('/') || rawResource.startsWith('./') || rawResource.startsWith('../') || rawResource.endsWith('.md')) {
          let cleanTarget = rawResource;
          if (cleanTarget.startsWith('/')) {
            cleanTarget = cleanTarget.slice(1);
          } else {
            try {
              const docDir = path.dirname(mdPath);
              const resolved = path.resolve(docDir, cleanTarget);
              cleanTarget = path.relative(bundleRoot, resolved);
            } catch (e) {}
          }
          let rel = cleanTarget.split(path.sep).join('/');
          if (rel.endsWith('.md')) {
            rel = rel.slice(0, -3);
          }
          if (rel && !links.includes(rel)) {
            links.push(rel);
          }
        }
      }
    }

    concepts.push({
      id: conceptId,
      type: String(frontmatter.type || 'Unknown'),
      title: String(frontmatter.title || conceptId),
      description: String(frontmatter.description || ''),
      resource: String(frontmatter.resource || ''),
      tags: tags.map(String),
      body: body || '',
      links_to: links,
      status: frontmatter.status || 'stable',
      stale_after: frontmatter.stale_after || '',
      verified: frontmatter.verified || [],
      generated: frontmatter.generated || {},
      sources: sources,
      usage_window: frontmatter.usage_window || null,
      runtime: frontmatter.runtime || '',
      parameters: frontmatter.parameters || [],
      computation: frontmatter.computation || '',
      executor: frontmatter.executor || null,
      attester: frontmatter.attester || null
    });
  }

  const graph = buildGraph(concepts);
  const templateDir = path.dirname(__dirname);
  const templatePath = path.join(templateDir, 'templates', 'viz.html');
  const cssPath = path.join(templateDir, 'static', 'viz.css');
  const jsPath = path.join(templateDir, 'static', 'viz.js');

  const template = fs.readFileSync(templatePath, 'utf8');
  const css = fs.readFileSync(cssPath, 'utf8');
  const js = fs.readFileSync(jsPath, 'utf8');
  const name = path.basename(bundleRoot);

  const html = template
    .replace('/*__VIZ_CSS__*/', () => css)
    .replace('/*__VIZ_JS__*/', () => js)
    .replace('__BUNDLE_NAME__', () => JSON.stringify(name))
    .replace('__BUNDLE_DATA__', () => JSON.stringify(graph));

  fs.mkdirSync(path.dirname(outPath), { recursive: true });
  fs.writeFileSync(outPath, html, 'utf8');

  console.log(JSON.stringify({
    success: true,
    concepts: concepts.length,
    edges: graph.edges.length,
    bytes: Buffer.byteLength(html, 'utf8'),
    output: outPath
  }));
}

Bundle Migration & Upgrade

The /okf-upgrade skill automates the migration of legacy OKF v0.1 bundles to the modern OKF v0.2 format, correcting schema definitions and rewriting link labels in-place.

  • Converts legacy timestamp keys into structured generated: { by, at } properties.
  • Migrates inline body # Citations bullet lists to YAML frontmatter sources lists.
  • Fixes non-descriptive / bare markdown links (e.g. [target.md](target.md)) by looking up target titles.
  • Appends the standard okf_version: "0.2" compatibility flag to the bundle index.
  • Automates post-migration check verification using the drift linter.

2. **Citation Migration & Provenance Preservation (§5.1, §13.1)**:

3. **Version Check (§8, §12)**:
   - Inserts `okf_version: "0.2"` into the frontmatter of the bundle-root `index.md` file.

4. **Actor Normalization (§5.1, §7)**:
   - Normalizes non-standard `agent:<name>` actor formats in `generated.by`, `verified[].by`, and `sources[].author` to `<producer>/<version>` (e.g. `agent:Antigravity/3.5-Flash` -> `Antigravity/3.5-Flash`).

5. **Log Date Heading Normalization (§9)**:
   - Formats `log.md` date headings to ISO 8601 `YYYY-MM-DD` and merges duplicate consecutive date sections.

6. **Bare Link Auto-Fixing (§6.1)**:
   - Replaces bare/non-descriptive link labels (e.g. `[doc.md](doc.md)`) outside code blocks with the target concept's `title`.

7. **Lint Verification (§11)**:
   - Automatically runs `okf-lint` on the target bundle upon completion to verify compatibility.

  const workspaceRoot = process.cwd();
  let bundleRoot = path.join(workspaceRoot, 'docs', 'okf');
  if (!fs.existsSync(bundleRoot)) {
    bundleRoot = path.join(workspaceRoot, 'okf');

    let body = getConceptBody(content);

    let modified = false;

    // 1. Upgrade timestamp -> generated
    if (fm.timestamp && !fm.generated) {
      fm.generated = { by: `human:\${user}`, at: fm.timestamp };
      delete fm.timestamp;
      modified = true;
    }

    // 2. Auto-fix bare links in body
    const fixResult = autoFixBareLinks(body, bundleRoot, mdPath);
    if (fixResult.modified) {
      body = fixResult.newBody;
      modified = true;
    }

    if (modified) {
      const newFmText = serializeFrontmatter(fm);
      fs.writeFileSync(mdPath, newFmText + '\\n\\n' + body.trim() + '\\n', 'utf8');
    }
  }
}

Bundle Hygiene & Lifecycle Pruning

The /okf-prune skill manages bundle hygiene by detecting and safely archiving or removing obsolete knowledge documents across four critical lifecycle categories.

  • Stale concepts: Flags concepts whose stale_after expiration instant has passed.
  • Deprecated concepts: Relocates concepts marked status: deprecated from active listings to archive/.
  • Ghost concepts: Catches concepts referencing deleted local source code files or missing assets.
  • Orphaned concepts: Discovers concepts disconnected from the knowledge graph with zero inbound links.
  • Automated Index & Log sync: Updates index.md and appends pruning audit records to log.md.

# `okf-prune` Workflow

Maintain knowledge bundle hygiene through automated concept lifecycle pruning, archiving, and garbage collection aligned with OKF v0.2 (§5.4, §5.5, §6.2, §10).

## Overview

Over the lifecycle of a codebase, concepts change:
- Features are deprecated or removed (`status: deprecated`, §5.4).
- Temporary contracts or deadlines expire (`stale_after`, §5.5).
- Underlying source code or computation files are deleted, leaving ghost concepts with missing local `resource`, `sources`, `computation`, `executor.resource`, or `attester.resource` files (§6.2, §10.2).
- Concepts become disconnected and orphaned with 0 inbound links (across `index.md`, body cross-links, and `sources` concept lineage links).

`okf-prune` systematically audits the bundle, identifies candidates for removal or archiving, moves them safely to `archive/` (or permanently deletes them), updates `index.md`, and logs the changes in `log.md` (pass `--viz` to also refresh `viz.html`).

## Usage

```bash
# 1. Audit / Check Mode (Read-Only)
# Scans bundle and reports candidates without making changes. Exits with code 1 if prunable items exist.
node okf-prune/scripts/prune.js --check [--bundle <path>]
node okf-prune/scripts/prune.js --dry-run
npm run okf:prune:check

# 2. Archive Mode (Default Safe Action)
# Moves matching concepts to archive/, marks status: deprecated, and updates index.md and log.md.
node okf-prune/scripts/prune.js
npm run okf:prune

# 3. Permanent Deletion Mode
# Permanently removes candidate concept files from disk and cleans up index.md.
node okf-prune/scripts/prune.js --delete

# 4. Filtered Pruning
# Target specific categories instead of all prunable concepts:
node okf-prune/scripts/prune.js --stale       # Only expired stale_after concepts
node okf-prune/scripts/prune.js --deprecated  # Only status: deprecated concepts
node okf-prune/scripts/prune.js --ghosts      # Only concepts with missing local resource/source/computation files
node okf-prune/scripts/prune.js --orphans     # Only unlinked / isolated concepts

# 5. Machine-Readable JSON Output
node okf-prune/scripts/prune.js --check --json
```

| `--json` | Emits structured JSON result | Same as mode | 0 / 1 |

## Pruning Criteria & Rules

1. **Expired Concepts (`--stale`, §5.5)**
   - Concept has a `stale_after` timestamp in frontmatter.
   - Evaluated as `Date.now() >= new Date(stale_after).getTime()`.
   - Action: Archive or re-verify.

2. **Deprecated Concepts (`--deprecated`, §5.4)**
   - Concept frontmatter contains `status: deprecated`.
   - Per OKF v0.2 §5.4, deprecated concepts are kept for history and links but should not remain in active concept listings.
   - Action: Move to `archive/` subfolder and update `index.md` listing.

3. **Ghost Concepts (`--ghosts`, §6.2 & §10.2)**
   - Concept has a local path in `resource`, `sources` (string or `{ resource }` object), `computation`, `executor.resource`, or `attester.resource` whose file has been deleted from the repository. External URI schemes (`https://`, `bigquery://`, `gs://`, etc.) and scope descriptors (§5.1) are excluded.
   - Action: Clean up or archive to prevent drift errors.

4. **Orphaned Concepts (`--orphans`, §5.1 & §6.1)**
   - Concept has 0 inbound links across `index.md`, active concept markdown bodies (outside code blocks), and `sources` concept lineage references.
   - Action: Archive or link into the concept hierarchy.

  if (isCheck) {
    printAuditReport(candidates);
    process.exit(candidates.length === 0 ? 0 : 1);
  }

      deleteConcept(item);
    } else {
      archiveConcept(item, bundleRoot);
    }
  }
}

Why This Approach is Effective

Eliminating the "Cold Start"

When an agent loads into a codebase with no memory, it is context-blind. Standard wikis sit outside git, going stale. Raw code is too dense. An OKF bundle represents a codebase map, directly versioned beside source code, feeding agents high-level semantic insights immediately.

Adaptive Context Scaling

Rather than feeding large chunks of files into LLM contexts, the index hierarchy allows progressive disclosure. The agent walks index files recursively, only ingesting detailed concept documents relevant to the scope of work, saving significant token overhead and latency.

Zero Documentation Rot

Because the upkeep check (/okf-maintain) is configured as model-invoked, updating the documentation isn't a human task that gets forgotten. It's a natural side-effect of code execution. Every code modification reactive-triggers the agent to verify and update the metadata concepts.

Brownfield Project Flow

Use the /okf bootstrapping skill first to scan the legacy codebase, file systems, and imports. Once the initial structure is built, commit the okf/ directory and place the notice in AGENTS.md, CLAUDE.md, or your agent's steering file to guide future modifications.

Greenfield Project Flow

You must run /okf once (or manually create an empty okf/ folder) to satisfy the maintainer's guard check. After initialization, okf-maintain automatically creates and updates concept files as the codebase grows.
